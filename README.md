# api.rahmamedical - خادم المزامنة والربط السحابي (Backend API)

محرك الربط والمزامنة التلقائي بين منصة زد (Zid) ونظام دفترة ERP لمؤسسة منال كامل حامد رحمة للتجارة.

## الميزات والوظائف الرئيسية
- 🔄 **مزامنة المنتجات التلقائية:** فاحص دوري كل 5 دقائق لنقل وتحديث الأسعار والمخزون من دفترة إلى زد.
- 🧾 **معالجة مبيعات وطلبات زد:** استقبال الويب هوك وفاحص أمان دوري لإصدار فواتير مسودة بدفترة.
- 🛡️ **صمام منع التكرار (Idempotency):** حماية كاملة ضد تكرار إصدار الفواتير أو المنتجات.
- ⏱️ **نقطة توقف ذكية (Watermarking):** حفظ تسلسلي لنقاط التوقف لمنع سقوط أي بيانات عند انقطاع الاتصال.
- 🔒 **أمان متقدم وريت ليميت (Rate Limiting):** حماية واجهات الـ API ونقاط الويب هوك.

## التشغيل والتثبيت

1. تثبيت الحزم:
```bash
npm install
```

2. بناء المشروع (TypeScript Build):
```bash
npm run build
```

3. إنشاء وتحديث جداول قاعدة البيانات:
```bash
npm run db:migrate
```

4. تشغيل السيرفر في الإنتاج:
```bash
npm start
```
